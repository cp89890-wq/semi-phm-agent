# 결정 기록 (Decision Log)

작업하면서 그날그날 쓴다. 한 항목 3~5줄. 나중에 면접 답변이 되는 파일이다.

양식:
```
## YYYY-MM-DD — 한 줄 제목
- 선택: 무엇을 했나
- 대안: 뭘 안 했나 (최소 하나)
- 이유: 왜 (데이터 크기, 누수 위험, 선행 연구, 시간 등)
- 결과/후속: 그래서 어떻게 됐나, 나중에 다시 볼 것
```

## 2026-11-05 — LLM 의 역할 제한
- 선택: 숫자 계산·모델링은 전부 코드(tools/). LLM 은 도구 선택·결과 해석·리포트 작성만.
- 대안: LLM 에게 센서값을 직접 주고 원인을 묻기.
- 이유: 표/시계열 데이터에서 LLM 은 통계 모델보다 정확할 이유가 없고 근거 없이 확신하는 경향. 검증 가능하려면 가설의 출처가 코드여야 함.
- 후속: 에이전트 가설 vs 실제 중요 변수 일치율을 eval/ 로 측정.

## 2026-11-05 — CMP 1차 EDA 결과 반영 (outputs/eda_cmp_notes.md)
- 선택: (1) 챔버(MACHINE_DATA)를 1급 변수로 두고 챔버별 성능 보고. (2) 제거율 >300 이상치 4건 제외. (3) 분할은 시간순.
- 대안: 전체 한 모델 + 랜덤 분할.
- 이유: 제거율이 챔버 2(~151) / 챔버 5(~77) 두 덩어리라 섞으면 챔버만 맞혀도 RMSE가 좋아 보임. TIMESTAMP-제거율 상관 +0.5 로 드리프트 있어 랜덤 분할은 누수. 이상치 4건은 정상의 25배.
- 후속: 랜덤 분할 vs 시간순 분할 RMSE 차이를 failures.md 에 기록 (누수 효과 정량화).

## 2026-11-05 — 평가 지표는 선행 연구와 동일하게
- 선택: CMP 는 저마모/고마모 구간별 RMSE (Lee et al. 2025 기준), 이온밀은 챌린지 공식 점수 + 분류 F1.
- 대안: 전체 RMSE 하나만 / 자체 지표.
- 이유: 비교 가능해야 "잘 됐는지" 판단 가능. 자체 지표는 검증 불가.
