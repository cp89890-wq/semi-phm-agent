작업하면서 그날그날 쓴다. 한 항목 3~5줄. 나중에 면접 답변이 되는 파일이다.

양식:
```
## YYYY-MM-DD — 한 줄 제목
- 선택: 무엇을 했나
- 대안: 뭘 안 했나 (최소 하나)
- 이유: 왜 (데이터 크기, 누수 위험, 선행 연구, 시간 등)
- 결과/후속: 그래서 어떻게 됐나, 나중에 다시 볼 것
```

## 2026-11-05 — CMP 1차 EDA 결과 반영 (outputs/eda_cmp_notes.md)
- 선택: (1) 챔버(MACHINE_DATA)를 1급 변수로 두고 챔버별 성능 보고. (2) 제거율 >300 이상치 4건 제외. (3) 분할은 시간순.
- 대안: 전체 한 모델 + 랜덤 분할.
- 이유: 제거율이 챔버 2(~151) / 챔버 5(~77) 두 덩어리라 섞으면 챔버만 맞혀도 RMSE가 좋아 보임. TIMESTAMP-제거율 상관 +0.5 로 드리프트 있어 랜덤 분할은 누수. 이상치 4건은 정상의 25배.
- 후속: 랜덤 분할 vs 시간순 분할 RMSE 차이를 failures.md 에 기록 (누수 효과 정량화).

쉬운 말로 (면접 답변용 초안 — 본인 문장으로 고칠 것):
- **챔버별로 나누는 이유.** 챔버 2는 제거율이 150 근처, 챔버 5는 77 근처다. 둘을 섞어 한 모델에 넣으면
  모델이 "챔버 2면 150, 챔버 5면 77"만 맞혀도 오차가 확 줄어든다. 그러면 RMSE 가 좋아 보이지만
  실제로는 센서가 아니라 챔버 번호만 본 것이다. 챔버 안에서 센서로 얼마나 더 맞히는지가 진짜 성능이라
  챔버별 RMSE 를 따로 본다.
- **랜덤 분할이 안 되는 이유.** 제거율이 시간이 갈수록 올라가는 추세(상관 +0.5)가 있다. 웨이퍼를 무작위로
  학습/검증에 나누면 검증용 웨이퍼 바로 앞뒤 시점의 웨이퍼가 학습에 들어가서, 모델이 "그 시기 제거율"을
  외워버린다. 실제 현장은 과거로 미래를 맞히는 것이니 시간순으로 앞을 학습, 뒤를 검증에 써야 정직한 숫자다.
- **이상치를 빼는 이유.** 4건이 4,100~4,300인데 나머지는 최대 163. 25배 차이면 물리적으로 같은 공정 결과일 수
  없고(측정·기록 오류로 추정), 두면 RMSE 가 그 4건에 끌려다닌다. 빼되, 뺐다고 적는다.

## 2026-11-05 — 평가 지표는 선행 연구와 동일하게
- 선택: CMP 는 저마모/고마모 구간별 RMSE (Lee et al. 2025 기준), 이온밀은 챌린지 공식 점수 + 분류 F1.
