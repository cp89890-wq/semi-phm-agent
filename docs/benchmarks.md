# 벤치마크 비교

같은 데이터, 같은 지표, 같은(또는 명시된) 분할로만 비교한다. 분할이 다르면 각주로 밝힌다.

## CMP (PHM 2016) — 재료 제거율 RMSE

| 방법 | 출처 | Low wear | High wear | 비고 |
|---|---|---|---|---|
| Moment12x4 | Lee et al. 2025 (arXiv 2503.01176) | 8.49 | – | 모멘트 특징 |
| RawSpace12x50 | 같음 | 7.95 | 5.32 | |
| PCA30 + 선형회귀 | 같음 | 8.18 | 3.97 | |
| AE + 클러스터링 + 선형회귀 | 같음 (제안) | 5.69* | 3.86 | *논문 내 수치 불일치 (4.77 vs 5.69) |
| **본 베이스라인 v0 (특징요약 + LightGBM)** | experiments/cmp_baseline.py, 2026-11-05 | 6.21 (ch456, n=327) | 5.64 (ch123, n=69) | 시간순 80/20 홀드아웃. 전체 6.11. 챔버 평균만 쓰는 naive 7.83 |
| (참고) 같은 모델, 랜덤 분할 | 같음 | 3.54 | 3.25 | **누수로 부풀려진 값** — failures.md #1 |
| **본 최종** | | | | |

분할 주의: 논문은 train/val/test 고정 분할(저마모 1616/354/354, 고마모 166/34/32). 저마모 ≈ 챔버 4-5-6 그룹(n=1610), 고마모 ≈ 챔버 1-2-3 그룹(n=368)과 수가 일치 → 논문의 low/high wear 구분 = 챔버 그룹으로 보임. 단 논문 분할이 시간순인지 랜덤인지 불명 → 직접 비교는 보류.
본 결과는 CV 라 직접 비교엔 한계 → 가능하면 같은 비율로 홀드아웃도 보고.
